The Fortran modules of [MiMA](https://eddy-stanford.github.io/MiMA/), generated by
[FORD](https://forddocs.readthedocs.io) from the doc comments in `src/`. The user
documentation (building, running, namelists, diagnostics) is on the
[main site](https://eddy-stanford.github.io/MiMA/).

The vendored AER RRTMG radiation code (`src/atmos_param/radiation/rrtm/rrtmg_*`) is
not included.
